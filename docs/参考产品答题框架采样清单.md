# 参考产品答题框架采样清单

2026-10-18更新：已取得参考仓库公开的14组提示词，见 [提示词原文](reference-medical-rag/提示词原文.md) 与 [应用对照](reference-medical-rag/提示词应用对照.md)。下面的采样改为可选，仅用于观察公开模板未明确规定的输出样式；无需为了提取提示词继续反复询问参考产品。界面没有来源时直接记录“未展示”，不要求提供不存在的来源截图。

目标：学习参考产品如何理解问题、组织答案和承接追问，将可取的结构转化为本项目的搜索与回答模板。我们学习排版和信息组织，不照搬医院评价、医疗结论或无法核实的事实。

当前截图已经能观察到“简短回应 → 按地区分组 → 加粗医院名称 → 相关特点 → 选择思路”的框架。截图不能揭示对方内部的系统提示词、真实搜索关键词、检索工具或全部证据，因此不把推测写成对方的真实实现。

## 先收集这8组即可

每组请从新对话开始；标有“继续追问”的问题要在同一对话中按顺序提问，保留上下文。下列问题可直接复制。

| 编号 | 类型与直接提问 | 继续追问 | 需要观察的框架 |
| --- | --- | --- | --- |
| A01 | 东莞有哪些医院？ | 我更关注公立医院，按所在区帮我分一下。 | 普通名单如何分组、数量、每家介绍长度；是否擅自变成排名 |
| A02 | 广东省有哪些医院？先列举8到10家，尽量覆盖不同城市。 | 广州和深圳的分别列一下。 | 大范围如何分层、是否只集中一城；明确部分名单与总数 |
| A03 | 广州有哪些医院可以了解乳腺癌诊疗服务？希望介绍相关科室和各自特点。 | 如果更希望在东莞就诊呢？ | 疾病相关搜索、科室与医院特点、城市切换后的主题保留 |
| A04 | 我想比较杭州和东莞的乳腺癌诊疗医院，先分别介绍本地选择，不需要扩展到其他城市。 | 如果允许跨市，再增加广州的选择。 | 多地区分组、每组条目、何时允许邻近城市；不越过用户范围 |
| A05 | 广东省人民医院有哪些重点科室？请区分重点专科和普通科室。 | 乳腺相关的门诊和科室具体怎么区分？ | 认定与自述如何区别、专科深度、何时说明信息缺口 |
| A06 | 广东省人民医院和中山大学附属第一医院，乳腺相关服务应该怎么比较？ | 先比较相关科室、院区位置和挂号方式，不给治疗方案。 | 表格还是分段、比较维度、缺失项、是否避免无依据“最好” |
| A07 | 广东省人民医院有哪些院区，分别在哪里？ | 从广州南站出发，应该先确认哪个院区？ | 地址对应、交通信息、院区不明确时如何追问 |
| A08 | 第一次去广东省人民医院乳腺相关门诊，官方预约渠道和挂号步骤是什么？ | 如果没找到实时号源，你能确认哪些信息，哪些不能确认？ | 步骤、官方渠道、实时信息不足时如何回答 |

## 第二批：补齐边界与非医院问题

| 编号 | 直接提问或操作 | 需要观察的框架 |
| --- | --- | --- |
| B01 | 广东省一共有多少家医院？请给统计年份和口径，不用示例名单代替总数。 | 精确统计与列举医院是否分开 |
| B02 | 在广州异地就医，医保备案和医院费用报销通常要确认什么？ | 政策条件、步骤、适用地区和时间 |
| B03 | 附近哪家医院的呼吸科更适合去看看？（不先提供城市） | 缺少地区时是否只追问必要信息，不虚构定位 |
| B04 | 广州有哪些医院现在还有今天的乳腺科号源？ | 实时工具能力边界、失败表达、替代路径 |
| B05 | 东莞有哪些医院开设呼吸内科？不要只给健康证体检机构名单。 | 搜索来源是否匹配就诊需求，而不是碰巧包含医院名称 |
| B06 | 上传一份匿名CT报告，先不输入问题。然后问：“这份报告的检查项目是什么？” | 附件在对话中的呈现、首轮报告概述与具体追问的长度区别 |
| B07 | 对同一份匿名报告问：“检查所见和诊断意见分别说了什么？哪些是原文，哪些是解释？” | 原文/解释区分、术语解释、避免推断诊断 |
| B08 | 对同一份报告继续问：“不用整理复诊清单，只解释‘肺结节’是什么意思。” | 是否遵守本轮问题，不被前文复诊意图绑定 |
| B09 | 再明确问：“现在帮我整理复诊要带的资料清单，缺少的内容单独列出。” | 只有明确请求时进入复诊准备；已具备/待准备的区分 |
| B10 | 依次问：“胸部CT平扫和增强有什么区别？”“用两句话解释就行。” | 一般科普与短答控制，是否仍强行套长模板 |

这些问题用于观察回答方式，不预设参考产品一定能答对。报告可使用已有匿名样本或虚构病例，不需要提供真实身份资料。

## 每组需要哪些文字和图片

优先保留完整回答文字，长截图作为排版参考；只有截断图片会看不到结尾、依据和追问方式。

1. **问题及上下文截图**：能看到本轮问题；多轮组要保留上一轮相关内容。A03、A04、A06尤其需要完整多轮顺序。
2. **完整回答文字**：保留标题、粗体、编号、列表、表格和结尾；界面能复制Markdown时优先保留Markdown。
3. **完整回答截图**：一张长截图，或依次截“开头—中段—结尾”；表格、折叠区分别截清楚。不要只截第一屏。
4. **引用依据截图**：若有“来源/搜索结果/查看依据”，展开后保留标题、URL、日期；若界面没有展示，注明“未展示”即可。
5. **搜索过程截图（可选）**：只有产品主动显示搜索关键词、网页读取或工具步骤时才保留；不用猜测隐藏过程，也不必询问其系统提示词。
6. **你的判断**：哪一处觉得好、哪一处不喜欢，用一句话标记即可，例如“喜欢按城市分组”“每家介绍太长”“不想每次都问是否继续”。

界面缩放尽量一致，文字可读即可；无需反复调整到某个固定截图尺寸。

## 我们拿到样本后会提取什么

| 维度 | 转成项目里的规则 |
| --- | --- |
| 用户要名单、比较、位置还是疾病就诊方向 | 问题类型选择不同模板，避免全部输出地址列表 |
| 城市、疾病、科室、医院等级、是否允许异地 | 搜索条件和多轮继承规则，不靠同一个宽泛关键词 |
| 开头直接答什么、何时分组 | 短开场、地区/服务方向分组，避免长篇来源前言 |
| 每家医院写哪些项 | 名称、相关科室、可核实特点、位置；缺少证据就省略 |
| 如何表述优势与选择 | 有依据的服务特点和有条件的考虑，不复制“最权威/最好” |
| 证据不足或工具失败 | 先保留有依据部分，明确未核实项，不让用户重复提供已有城市 |
| 结尾是否追问、追问几个 | 只在有实际筛选价值时最多问一个，不每次固定邀问 |
| 回答长短及视觉层级 | 小标题、连续编号、粗体标签、短段落；简单追问保持短答 |

## 本次已落实与待采样范围

本次已新增医院咨询的8类回答框架：名单、疾病就诊选择、重点科室、比较、位置交通、预约、费用医保、数量统计，其他服务使用简短通用框架；搜索保留明确的公共疾病/科室方向。框架事实必须来自本轮资料。

报告解读、一般科普和复诊清单保留各自工作流，已接入适用的查询规划、资料判断、上下文规则或事实核对，见 [接入记录](reference-medical-rag/接入记录.md)；B06—B10用于后续精细优化。多地区查询已加入分地区规划、预算保留和缺失地区检查，实际证据不足时仍需明确部分覆盖，不能仅靠增加城市标题宣称完成。

模板入口：`apps/api/app/followup/hospital_templates.py`；公共检索规划入口：`apps/api/app/followup/hospital_planner.py`；回答装配入口：`apps/api/app/followup/chat.py`。
