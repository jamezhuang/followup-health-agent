# 公共资料信源使用须知

适用于医院服务咨询、就诊指引、医保政策和一般医疗科普。搜索可发现任意医院的公开官网，不以已登记域名名单作为全部可查询医院范围。

## 一、优先采信的官方资料

| 渠道 | 适用问题 | 核验要求 |
| --- | --- | --- |
| 医院官网、官方公众号/服务号、官方预约平台、院内通知、门诊和住院指南 | 院区地址、交通、挂号、科室、电话、院内服务及办理流程 | 对应目标医院和院区；公众号须有机构认证或官网关联证据；只引用实际读取的内容 |
| 国家及地方卫健部门、政务服务平台 | 医疗机构信息、管理制度及就医政策 | 核对管辖地区、文件范围及生效状态 |
| 医保局及其官方政策文件 | 医保资格、报销、异地就医和结算政策 | 政策以有管辖权的医保部门现行规则为准，医院指南补充院内操作 |
| 临床指南、药典、药品说明书、权威教材、国家健康科普资料 | 疾病基础知识、检查含义及一般医疗科普 | 核对版本、适用人群、疾病及内容范围；不把科普转换为个体诊疗方案 |

已核对的示例：南方医科大学珠江医院官网 https://www.zjyy.com.cn/ 。该域名只是来源实例，不限制其他医院的动态发现。

官网身份和事实可靠性分别核验：搜索排名、标题含“官网”、页面可读，以及管理员发布，均不能单独证明官方网站身份。新网站可通过已读取政府页面的实际机构链接建立来源关联；未经核验的页面必须按实际来源归属，不称为“已核验官网”。已登记网站也要核对所问事实，不等于该站每篇文章都适用于当前任务。

院内公示由用户提供时须标注其来源和日期，不冒充系统已到现场核实。官方电话只提供有依据的号码，未实际拨打不得声称电话核实。登录受限、无法读取的公众号或预约平台内容不能声称已经获取。

## 二、辅助参考资料

官方没有直接说明所问细节时，可补充地图平台、媒体民生报道、点评平台、患者就诊分享和第三方设备服务商公开说明；标明来源、适用范围及限制。媒体名称、平台认证和患者“真实经历”均不自动转化为医院官方规定。

地图和公交、地铁运营方可用于地点和交通信息。地图上的地点数量不能证明医院院区总数，路线时刻和运行状态也不保证实时有效。

共享轮椅、充电宝等服务优先核对目标医院/院区及实际运营商。只有适用证据支持时才给金额，并注明是运营商参考规则，以及“最终以现场公示、院内实际为准”。无适用证据时不报押金、单价或价格范围。

其他医院、同类型三甲医院的服务商规则仅可作为明确归属的背景例子，不推定目标医院使用相同运营商、价格或退费规则。不能把网友个人经历当作确定官方政策。

## 三、时效与冲突

1. 网友或第三方说法与适用于目标问题的现行官方资料冲突时，舍弃冲突的网友结论。
2. 官方资料之间冲突时核对发布主体、医院/院区、地区、人群、发布日期、生效日期、撤销和更正关系。较新网页不必然比仍有效的规范更有权威。
3. 无法消解的冲突明确说明待核实，不按搜索结果数量投票。
4. 采集时间、网页读取时间不冒充发布日期；未见发布日期则记为未知。旧公告不自动代表当前规定。
5. “最新”限于本轮实际获取并核对到的资料，不承诺实时号源、排班、交通或现场价格。缓存和本地历史快照须保留来源与时间；检索失败不掩盖为最新核实。

## 四、回答与诊疗边界

能核实的部分先回答，未核实的事项单独说明。不因缺一个细节而整体拒答；也不为补全答案编造事实。

仅做就诊指引和一般科普，不作个体诊断、不开处方、不自行给出调药方案。个体诊疗以线下医生结合实际情况的判断为准。必要限制与具体事项一起说明，不给每个短问题附加无关的长篇免责声明。

## 五、当前实现范围

回答生成、资料充分性评估和回答核对共用信源规则；最终来源排序优先保留已验证来源。已支持公开发现未知网站，并为指定医院的问题增加对已读取页面实际服务链接的有界探索。

公众号登录、电话拨打、院内现场核查和地图实时路线接口未因此自动获得；可读取公开页面不代表拥有这些渠道的完整访问能力。来源冲突按上述规则由模型核对，不宣称已实现自动法律效力判定。
