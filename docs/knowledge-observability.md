# admin 知识任务与引用观测

入口：管理员登录 → 后台管理 → 运行观测 → 知识任务与引用观测。

## 本阶段完成

- 汇总文件入库、审核发布的排队、处理中、已完成、失败数量，统计范围为对应队列表的全部记录。
- 最近知识任务失败按更新时间合并显示10条，提供任务类型、ID、尝试次数和可公开错误原因；“前往处理”或“管理知识任务 / 重试”进入已有公共知识库任务面板。
- 最近100条对话任务的引用检查统计，以及最近10条失败/不可用记录；“查看执行链路”复用原有管理员链路详情。
- 公共模型回答完成引用检查后，增加“核对最终引用”阶段事件，记录状态，不记录正文。
- 空数据通过率显示“—”。不自动重试、不重新发布、不改变历史结果。

## 统计口径

引用检查通过数为 passed + repaired。尝试数排除 not_recorded（历史未记录）和 not_applicable（普通聊天等不适用）；failed、failed_after_answer_review、unavailable 计入分母但不计通过。引用格式核验率不代表答案事实正确率。

入库/发布统计按全量任务计数，引用统计按最近100条对话任务计数，原模型耗时/Token面板按最近10000次模型调用计数。不同窗口不能混用来推断整体业务成功率。

新汇总接口只返回允许的状态元数据，不包含提问、回答、患者ID、原文、文件名、文件字节或来源摘录。已有管理员执行链路沿用其权限检查，本阶段未扩大普通用户访问权限。

队列仍为单API进程的SQLite队列，面板不等于新增分布式调度能力。任务重试遵守原版本检查、队列上限和最多3次限制，需管理员在任务面板主动触发。

## 验证

70项相关后端测试通过，覆盖空统计、精确分母、100条窗口、字段隐私与管理员权限及已有引用/入库发布回归。前端类型检查通过。

5个不同浏览器场景通过：后台滚动、知识观测汇总与跳转、批量上传、入库发布检索撤回、引用展示。使用独立合成测试服务；未将测试失败任务写入正式知识库。
