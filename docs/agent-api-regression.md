# Agent 接口与回答回归

在 `apps/api` 目录运行：

```powershell
# 本地接口与确定性业务回归，不调用付费模型
.venv/Scripts/python.exe scripts/run_agent_regression.py

# 同时重新调用真实模型：100题意图、16个端到端场景、4个单位比较
.venv/Scripts/python.exe scripts/run_agent_regression.py --live
```

每次结果单独保存在 `apps/api/data/agent_regression/<UTC时间-随机ID>/`，包括 `REPORT.md`、`summary.json`、JUnit XML、各阶段日志和真实模型原始结果。UTC目录名只用于唯一定位。脚本记录源码指纹；`--live` 强制生成新的调用记录，不把缓存结果当新测量，也不覆盖原始实验报告。没有完整汇总、或有 `ABORTED.md` 的目录不属于通过记录。

## 检查范围

- 接口契约：参数校验、未登录、跨账号访问、跨复诊对象资料隔离、未确认资料、CRUD和版本冲突、异常恢复，以及失败请求不生成任务、不修改报告。
- 确定性业务：意图与操作分流、医院指代、未核对附件提示、报告问答、复诊清单和token计账。
- 真实模型：意图严格匹配、端到端程序检查与辅助语义裁判、单位可换算/缺单位/量纲不同/同单位四种情况。
- 观测：业务链token与辅助裁判分开，未知用量不算零；端到端每次任务的P50/P95耗时；失败题号及原始返回保留。

`执行完成`、`接口测试通过`、`回答质量通过` 是不同状态。真实模型严格门禁默认要求100条意图、16个端到端和4条单位题全部通过；不因已知失败就降低标准。任何失败会让统一入口返回非零退出码，适合接入CI。离线通过只代表已运行的确定性检查通过，不代表真实模型已通过。

## 成本与耗时比较

```powershell
.venv/Scripts/python.exe scripts/run_agent_regression.py --live --baseline data/agent_regression/<上一轮ID>/summary.json
```

`summary.json` 会列出相对上一轮的意图token、端到端业务token与任务P95变化。默认只测量，不凭单轮数据设置性能门槛；需要门槛时显式传入 `--max-e2e-tokens <总token上限>` 和 `--max-e2e-p95 <秒数>`。辅助裁判token单独记录；单位题的用量当前含裁判，字段明确标注。

## 适用边界

名单外医院的联网探测可单独运行 `.venv/Scripts/python.exe scripts/run_cross_province_probe.py`。它使用未登记医院名称，不向agent提供网址，输出位于 `data/agent_eval_v2/round4/cross-province-*`。官网名单是已核对来源的优先提示，不是医院查询能力白名单。原始搜索、网页可读、来源可信和答案完整分别判断；尤其不能把六家能取到公开资料写成六家取得官网。排序前的完整候选池与逐页读取诊断用于区分召回、截断和读取故障。该联网探测尚未默认纳入离线入口。

测试使用隔离数据库和合成资料，不连接生产患者数据库。端到端使用真实FastAPI ASGI请求，未经过浏览器或真实部署网络；外部医院搜索关闭，不能验证实时官网内容。语义裁判与业务使用同模型，可能漏判，因此不能替代证据命中检查或独立人工评审。未纳入本入口的65题检索消融、真实外网和浏览器测试须单独执行，不能视为覆盖。

仅增加了可本地运行的统一入口，未配置外部CI或定时任务。
