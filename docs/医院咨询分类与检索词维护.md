# 医院咨询分类与检索词维护

本次将用户提供的《医院常见问答与应答模板手册》九类问题改写为 CareBrief 的检索分类和回答框架。源文件未修改，示例中的地址、楼层、电话、金额和排班没有导入知识库。

仍保持 daily 和 followup 两个入口。医院咨询是 daily 内部的工具选择；报告问答、已确认资料归档调取和用户主动要求的复诊清单沿用 followup 流程。新规则不自动保存报告或生成清单。

## 手册分类接入位置

| 类别 | 检索及回答重点 |
| --- | --- |
| 就诊前咨询 | 预约、挂号、放号、院区、开诊、证件、停车 |
| 就诊过程 | 报到、过号、检查、缴费、报告领取及打印 |
| 医保费用报销 | 参保地、就诊地、政策适用条件、办理材料与渠道 |
| 入院住院出院 | 办理地点、手续、材料、时间、病区陪护探视 |
| 科室与医生 | 一般分诊、实际科室服务、医生专长、多学科会诊 |
| 病历与证明 | 本人或代办、门诊或住院、材料、办理时限 |
| 体检中心 | 套餐、预约、按具体项目准备、报告与解读服务 |
| 便民及急诊 | 设施、轮椅、失物、投诉、急诊服务渠道 |
| 常见医疗疑问 | 原因、治疗知识、副作用、复查、生活方式、传染与遗传 |

医院的实际渠道、具体科室、医生排班、费用和医保资格仍必须有检索依据。第九类保留一般医学科普能力，不照搬客服手册的“医疗问题一律转医生”规则。不能冒充医院导诊、承诺代联系、床位或治疗结果。急重症求助建议不应等待查询结果。

## 疾病与科室检索线索

`apps/api/app/followup/hospital_knowledge.py` 集中维护 `CLINICAL_PROFILES` 和 `SERVICE_CATEGORIES`。新增类别只需维护相应词条，核心检索循环无需逐病修改。模型仍可提取词表外、用户明确说出的公共需求；词表是降级补充，不是允许提问的白名单。

运动损伤覆盖韧带断裂、撕裂、损伤、拉伤，前后交叉韧带、侧副韧带、半月板、肩袖、跟腱、肌腱肌肉损伤，以及骨折脱位、脊柱及关节相关疾病。关联运动医学科、骨科或更具体的科室仅用于发现网页。

其他线索覆盖多部位肿瘤、血液疾病、心血管、内分泌、神经、呼吸、消化、肝胆泌尿结石、眼耳鼻喉、皮肤、精神心理、生殖和风湿免疫方向。

第一条查询保留用户原始疾病、地区和治疗要求；后续可分别使用同义表达和相关科室发现更多页面，最终核对仍按原始需求。各路结果取并集，去重后融合排序，并优先读取不同医院。不会把韧带损伤自动断言为前交叉韧带断裂，也不将症状推断成疾病。模型改写为空或不可用时保留本地检索线索。明确的身体结构不能在扩展时替换成另一结构。

## 地区和证据核对

珠三角地区可由其九市的正文地点提供地区匹配，粤港澳大湾区另外包含香港和澳门。不会把整个广东省或其他省份的机构自动归入珠三角。城市匹配仅解决地理条件，不能证明相关诊疗能力。

正文仍需提供医院主体、相关疾病或损伤、要求的治疗方式等证据。同义表达需要逐字引用的语义核对；检索线索或普通科室设置不能自动转化成“擅长”、排名或疗效结论。语义核对候选可由相关科室及同义检索词发现，但通过标准不因此放宽。

同一家医院的多页证据现在可以联合核对。只允许完整名称一致且公开域名一致的页面组成证据组，原始正文、链接和来源 ID 不合并改写；近名、未确认别名、跨域页面、医生履历和目录不会自动拼接。地区及科室或治疗的证据可以分属不同页面，模型必须返回原文短引和实际支持的来源 ID。等级等额外条件不再关闭语义核对，但必须给出相应原文证据。

结果区分 `confirmed_service`（有当前请求相关诊疗服务证据）和 `related_department`（仅确认相关科室，尚未核实所问疾病治疗或术式）。后一类可保留并单独标明，不能宣传为已开展治疗、擅长或排名靠前。后续页面可将后一类提升为前一类。管理员检索诊断分别显示两类医院数，初筛未通过不等于最终全部丢弃。

网页、轮次、浏览器和总时间预算仍有效；前两轮疾病选院优先读取最多四个不同机构候选，每轮可做一次有界语义核对，较早轮次未读页面和未完成证据保留到后续补查。存在缺口时允许继续定向核对，不通过无上限增大搜索范围实现覆盖。

本次设计参考了 LangChain SelfQueryRetriever 的结构化查询、LlamaIndex QueryFusionRetriever 的多查询结果融合，以及 LangGraph Adaptive RAG 的相关性与回答依据分开检查；没有复制或替换整个框架。

## 验证与边界

新增测试位于 `apps/api/tests/test_hospital_knowledge.py`，检查无模型词条提取、原始需求保留、身体结构保护、症状不推断诊断、珠三角范围、手册九类框架和路由、空模型改写的保底行为。

例如“珠三角地区有哪些医院擅长处理韧带断裂手术”应解析为：地区珠三角地区，损伤韧带断裂，治疗手术，检索科室运动医学科和骨科，补充表达韧带损伤。不能再退化成普通医院名录。

这些变更扩展问题理解与检索覆盖，并没有新增已核实的医院事实库，也不保证每轮能取得足够正文。网页访问失败、预算限制、资料不完整及外部供应商故障仍可能造成部分回答。
