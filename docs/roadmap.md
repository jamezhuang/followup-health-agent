# 后续开发完善方向

更新日期：2026-10-19。本页集中记录待开发、待优化和待扩大验证的工作。下列内容是计划与验收目标，不代表已经接入或已经达标；已实现能力与实测成果见[项目主页](../README.md)。

## 一、回答质量与知识覆盖（优先）

| 方向 | 后续工作 | 验证方式 |
|---|---|---|
| 提示词精简与任务覆盖 | 去除重复约束，强化子问题拆分、来源年代和缺失字段请求；比较局部收益与总成本 | 固定证据配对冒烟；同时记录要点覆盖、无依据陈述、输入/输出/总Token及耗时 |
| 跨省医院与复杂选院 | 扩大真实官方来源样本，增强同名机构区分、官网发现、不可读页面回退和多院区证据完整性 | 按地区、机构、服务拆分评分；统计候选发现、正文读取、信源核实和答案覆盖，不用页面数量替代完整性 |
| 检索与核验成本 | 优化候选池、重排预算和按风险核验，减少没有质量收益的额外模型请求 | 固定语料消融，比较证据组召回、完整证据命中、核验误拦截/漏检、实际Token |
| 真实病例与独立评估 | 补授权脱敏报告、药物记录与患者备注，建立独立留出集及专业复核流程 | 按患者/来源分组划分；区分资料整理、临床合理性和引用支持性，保留评审分歧 |
| 报告识别与上下文 | 扩展扫描件、复杂表格、单位及多轮更正案例，验证长对话压缩保真 | 字段准确性、来源定位、用户更正保留、缺失字段处理和上下文Token |

提示词和证据选择的历史试验保留在实验文档中，供复现与后续迭代使用；未达到推广条件的版本继续作为开发候选，不默认替换正式流程。

## 二、服务并发与中间件

| 方向 | 后续工作 | 验证方式 |
|---|---|---|
| MySQL | 规划业务与账号存储迁移、索引和事务边界，保留revision冲突保护 | 并发更新、事务回滚、死锁有界重试、连接池耗尽和数据迁移一致性 |
| Redis | 按实际需求引入缓存、跨实例限流与互斥；明确故障降级和旧结果淘汰规则 | 击穿、雪崩、穿透、发布后缓存一致性、限流边界、租约失效与过期持有者写入 |
| MQ与多实例队列 | 选择一种消息系统替换需要扩展的进程内队列，补消费幂等、重试、死信和事务发件箱 | 重复投递、乱序、提交后未确认崩溃、消息发送失败、积压和恢复时间 |
| 请求幂等与配额 | 完善外部工作流POST幂等键、租户密钥、调用配额和取消策略 | 同键同请求复用，同键不同内容冲突；重试不重复计副作用，配额跨实例一致 |

上述组件按业务瓶颈逐项接入。当前部署仍以SQLite和单API worker为运行前提；多实例上线前需要完成共享状态和租约测试，不能只增加worker数量。

## 三、可观测性与恢复能力

- 在当前run_id任务追踪之上，补浏览器/API、检索、模型、数据库及未来Redis/MQ之间的统一Trace ID、父子Span和耗时瀑布图。
- 扩大检查点恢复实验：覆盖不同故障位置、真实API工作流、重启、取消、超时及输入版本变化，统计端到端恢复率、重复副作用和实际成本。
- 补模型价格配置、费用核算、预算告警及明确的执行预算。未知用量仍单列，费用与Token区分。
- 验证指标包括受测Span覆盖、错误定位正确性、恢复完成率、复用比例、实际请求/Token及预算终止行为；不把组件微基准节省比例当所有业务的收益。

## 四、知识运营与更新管理

- 在手动更新巡检基础上，增加定时调度、过期提醒、快照差异高亮和变化分级。
- 增加真实网站样本，区分正文变化、导航/时间戳噪声与业务事实变化，保持人工审核发布。
- 完善入库失败文件、网页快照、检查点及历史任务的保留期限与归档清理。
- 统计变化检出和误报、成功读取、审核处理、更新滞后及失败重试，不以合成文本分类结果代表真实网站准确率。

## 五、平台集成与部署交付

- 基于已实现的工作流接口，完成Coze真实空间的插件导入、鉴权、异步结果查询和端到端联调。
- 部署独立服务，配置域名、HTTPS、监控、告警、备份与恢复演练；仓库公开与服务公网可用分别验收。
- 根据需求扩展OCR/ASR真实供应商联调、家人多账号授权和提醒渠道。
- 验收采用真实平台调用与服务健康记录，包括鉴权失败、超时、取消、重复请求、备份恢复和数据权限；不将接口本地通过视为平台已上线。

## 推进顺序

1. 优先完成回答与检索的小规模真实资料回归，再扩大独立评测。
2. 补幂等、事务、版本和故障注入验收后，按需求接MySQL、Redis及一种MQ。
3. 结合实际多实例运行补分布式追踪、调度和成本治理。
4. 最后完成平台真实联调与公网部署验收。

每轮记录当前基线、变更、样本、指标和失败分析；有明确收益且关键能力不退步的方案再进入正式流程。完整历史实验结论保留在各自报告，不因展示调整而改写原始结果。
