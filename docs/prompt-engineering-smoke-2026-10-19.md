# 提示词工程优化：第一轮冒烟对比

结论：完成8题、每题A/B各一次，共16次生成。B局部更简洁，但未证明整体质量提升，总Token增加8.92%，本轮不替换正式提示词。

## 实验条件

- A：执行时的CHAT_PROMPT快照；医院类P02/P03/P04/P08另外叠加HOSPITAL_PROMPT。两组均有相同的合成资料评测边界。
- B：在A后追加目标拆分、逐项匹配证据、缺项不阻塞其他问题、单位比较及复诊清单组织规则；未删减A现有规则。
- 模型：deepseek-flash，temperature=0，max_tokens=1800，thinking关闭。模型服务别名不等于可锁定的底层版本，完整执行配置已保存。
- 8道固定合成题；每道题证据完全相同，不联网、不检索、不调用核验器；不把评分要点发给回答模型。
- 奇数题AB、偶数题BA顺序执行；每组每题一次。即使temperature=0，也不能保证完全确定或可据此判断稳定性。
- A并不是所有分支的完整生产提示词。报告、复诊题在此使用通用回答政策，而非实际报告节点或复诊JSON节点的完整工作流。本轮仅测生成层提示词迁移能力，不能归因为生产端到端优化效果。
- 除16次生成外无额外模型裁判调用。逐题定性复核由本助手完成，非盲评、非独立人工评审，不评价临床正确性。

## 逐题观察

| 题目 | A/B差异与问题 |
|---|---|
| P01 抗生素＋无关食养资料 | 两组都直接回答且不跑题，B反而稍长，未见明确收益。 |
| P02 医院错字＋多问 | 两组覆盖地址、数量和已知交通；B显式纠错。两组都未直接追问出发地。合成路线场景下追问真实出发地的必要性存在用例设计问题。 |
| P03 同名医院跨省 | 两组均选择正确省份；A称“公开通知”，B保留“合成通知”，B来源表述更准确。 |

## 是否通过

接口与记录链路通过：16次生成均完成，证据固定、用量完整，可逐题对照。

提示词效果暂不通过推广门槛：B有局部改善，也存在共同遗漏；核心回应能力A原本已较好，没有证据说明B整体更优。合成来源限定不稳定需修正；不能因为没有诊断或自行改药指令就宣称“零幻觉”或“医疗安全已验证”。

下一轮仍只做冒烟：压缩重复指令而非继续追加，保留来源限定和数字精度；先修正开发样例，再冻结下一版。原8题已用于调试，后续重复测试属于开发集回归，不是独立留出集。尚未进行第二轮，未改生产提示词。
